# Frontend designs

Design documents describe the current frontend boundaries and intended
behaviour. Place a document in the narrowest category that owns the decision.

- [Routes](routes/README.md) — transport entry points, public contracts, and client-facing API flow.
- [Codebases](codebases/README.md) — application structure, shared ownership, and dependency direction.
- [Systems](systems/README.md) — editor, synchronization, storage, and cross-platform boundaries.
- [UI](ui/README.md) — the appearance and consistency a person should see. How to write it is in [conventions](../conventions/README.md).

Use [conventions](../conventions/README.md) for contributor rules and
[runbooks](../runbooks/README.md) for repeatable operational procedures.
