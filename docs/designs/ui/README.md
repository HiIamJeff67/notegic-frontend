# UI appearance

These documents describe what a person should see and the consistency that
appearance requires. They are not the rules for where code lives or which
component to import.

Write and reuse interface code through:

- [UI conventions](../../conventions/01-ui.md)
- [UI components](../../conventions/ui-components.md)
- [Style conventions](../../conventions/02-styles.md)
- [Icons and images](../../conventions/03-icons-and-images.md) and the [Icon map](../../conventions/icon-map.md)

| Document | What it answers |
| --- | --- |
| [Appearance](appearance.md) | The workspace look, color roles, type, density, motion, and the main surfaces |

When a visual decision changes, update the appearance document. When the way
that decision is written changes, update the matching convention.
